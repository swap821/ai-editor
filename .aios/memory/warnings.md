# Exploded Warnings

_Patterns that harmed >= 2x get promoted here, loudest at the top._

## DO NOT MANUFACTURE EXTRA APPROVAL GATES INSIDE APPROVED SCOPE

Two2026-10-03 continuations made no progress waiting on a small layout question despite direct human standing permission for scoped frontend edits/tests and the existing approved composition. An unanswered agent question does not revoke that permission. Re-audit exact scope and proceed with ordinary bounded repairs; ask for genuinely new authority. Git/backend/security/installs/large redesign remain gated. Automation itself grants nothing.

## ROLE QUERIES DO NOT ACCEPT AN EXACT OPTION

Testing Library ByRoleOptions does not contain exact; a string name is already exact. This fixture mistake repeated across source units and spent typecheck/repair time without advancing product behavior. Use plain string or anchored-regex role names, then run focused typecheck before broad gates. Do not copy ByText options into role queries.

## STATE SELECTORS CHANGE CAMERA LAYOUT THROUGH CSS SPECIFICITY

An added state selector can defeat an existing header-band or keyboard cap even if the declarations look unchanged. Removing Focus exclusions can apply only half a composition at neighboring breakpoints. Before broad layout qualification, check resting AND active geometry, actual control/content bounds and adjacent complete layout branches; align private camera eligibility with the CSS branch. Preserve unsupported compositions until a complete revision is built, and name their remaining debt.

## CORRECT RASTER BOUNDS ARE NOT A READABLE ACTIVE COMPOSITION

Regional glyph clipping and control masks can both pass while the actual organism remains hidden by DOM controls. Resting Focus captures do not establish active Focus: a retained workplane can cover the body, and expanded connection diagnostics can cover the compact workspace. Inspect active/expanded layouts, actual occlusion and readable persistent work together. Prioritize source changes to that relationship; do not substitute unchanged proof/docs, reduced particle counts or hidden work for the seven-phase vision. Fragment containment, body visibility, post-FX bleed and GPU cost are separate claims.

## REQUESTED CAMERA STATE IS NOT ACHIEVED VISIBILITY

Preserving old framing preserved a phone crop; requesting four OrbitControls angles with damping enabled only exercised a small front arc. Assert the installed controls' achieved angle, then project the actual protected anatomy/fused points against the real available region. Track observer target subscriptions and reproject after control resizing, not just camera metadata. Fit both width and height; nominal vertical FOV alone misses side/rear roots. Native captures, raw CPU geometry and actual GPU/device/all-posture acceptance are separate gates.

## QUIET MOTION IS NOT IDLE RENDERING

Paused shader/body clocks, hidden state and eventual repaint do not prove renderer idleness or continuity. Prior Float/bead defects and demand first-frame gaps escaped shallow checks. Use actual R3F/consumer scheduling: assert zero settled/hidden paints, first delta after controls/deferred assets/queued commits, same render owner, active timing and cleanup. Never lower DPR from deliberate idle samples. Native screenshots and substituted-renderer probes are not GPU/device performance acceptance.

## ONE WRITER PER WORKTREE

Do not infer ownership from an agent UI's "working" badge or from a stale
`RESUME.md`. Concurrent Claude/Codex writes caused stale handoffs, post-commit
dirty trees, and duplicated closeout work. Before edits, use
`python agent_coord.py brief --agent <name>` and hold the active `worktree`
builder lease. Reviewers remain read-only; transfer ownership only through a
hash-pinned handoff.
